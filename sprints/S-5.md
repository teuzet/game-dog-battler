# Навыки ботов: экзамены и шоукейс

- Тип: sprint
- Приоритет: 20

## Цель
Бот владеет базовыми навыками, каждый обучен отдельным генетическим поиском и сдаёт свой экзамен. Nick запускает билд, выбирает боту собаку и хозяина и смотрит, как тот проходит испытания.

## Готово, когда
- Раскрутка: собака раскручивает хозяина, оценка = максимальная скорость хозяина; экзамен пройден для каждой тестовой пары собака × хозяин
- Удар по статичной цели: старт на дистанции с нераскрученным хозяином, оценка = попадание с максимальной силой; экзамен пройден
- Удар по движущейся цели с упреждением: три уровня подряд с целями разного размера и скорости (не быстрее собаки, без мгновенной смены траектории); экзамен пройден
- Уворот: собака с хозяином на уровне с несколькими обученными собаками, которые бьют её как движущуюся цель; оценка = минимум полученного урона; заметно лучше, чем у бота без навыка
- Перемещение в точку с сохранением углового момента хозяина (по желанию): экзамен пройден
- Шоукейс в Unity: билд, где Nick выбирает собаку и хозяина бота и видит прохождение каждого экзамена с оценкой на экране

## Из обсуждения
Общее для трёх спринтов (решения Nick 11 ноя): бот управляет собакой напрямую, ход = направление движения + сила тяги; у собаки макс. сила тяги и макс. скорость, у хозяина масса. ИИ не зависит от схемы управления игрока. Спринты идут по очереди: «Ядро под ботов» → «Навыки ботов» → «Дуэль с ботом». Нейросети-гиганты и большие фреймворки не тащить; всё на чистом C# в Game.Core, поиск тулом evolve. Другие арены, стиль, идеи не трогать. Старый спринт S-1 «Боты: дуэль 1×1» остановлен, его duelist и заметка про планировщик с просчётом вперёд больше не план; код можно переиспользовать.
- Навык = обученное отображение «игровая ситуация → ход». Входы в системе координат собаки (положение и скорость хозяина, натяжение и угловая скорость, положение и скорость цели/угроз, стены), выход: направление + сила. Форму (параметрический контроллер или маленькая сеть с фиксированной структурой) выбирает исполнитель; числа ищет evolve, отдельный поиск (space) на каждый навык, обучение на разных парах собака × хозяин.
- Вопрос Nick, на который спринт должен ответить фактами: раскрутка, удар по статичной и удар по движущейся цели это три навыка или один с нарастающей сложностью. Позиция треда: скорее один навык «удар» с учебной лестницей (раскрутка → статичная цель → движущаяся, три уровня; статичная цель это движущаяся со скоростью 0). Попробовать оба варианта на одном экзамене и оставить лучший, в отчёте цифры.
- Экзамен отдельно от обучения: свежие сиды, фиксированные уровни, порог сдачи в данных. Оценки обучения не использовать как доказательство.
- Для уворота противники это уже обученные собаки с навыком удара по движущейся цели.
- Запасной эталон (добавлено тредом, Nick может отменить): для каждого экзамена посчитать результат перебора ходов с просчётом вперёд в симуляции (без обучения). Это потолок для сравнения; если генетический навык за разумное число поколений не сдаёт экзамен, показать в шоукейсе оба и сказать об этом в отчёте, а не тюнить бесконечно.
- Как навыки совмещаются в бою, решается в следующем спринте; здесь каждый навык должен уметь выдать свой желаемый ход и уверенность, чтобы их можно было смешивать с весами.
- Сначала экзамены и обучение в ядре, шоукейс в Unity последним. Задачи мелкие, вливать по одной.
