# Пример: забег с развилками

Учебная игра шаблона: показывает, как модули, события с тегами темпа, честные сенсоры и боты стыкуются с раннером `Game.Sim` и тулом фабрики `sim`. Контрактная фича первого спринта заменяет её модулями настоящей игры и удаляет эту папку вместе с `Game.Core.Tests/Example/` и примером в `Game.Core/Data/`.
