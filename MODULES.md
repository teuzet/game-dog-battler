# Карта модулей

Модуль владеет подсистемой целиком: своим состоянием, данными и правилами. `Simulation` шагает модули в порядке `GameSetup`. Модуль читает другой только через `sim.Need<T>(this, имя)` и только если назвал его в `DependsOn`. Контрактный тест сверяет `DependsOn` в коде с колонкой «Зависит от»: новая связь появляется правкой этой карты (её делает техлид при нарезке), а не попутно в фиче.

Порядок тика — сверху вниз. Модуль, стоящий выше, читает у стоящего ниже состояние прошлого тика.

| Модуль | Владеет | Зависит от |
|---|---|---|
| Arena | геометрия арены из `Data/arenas/`: границы, статичные препятствия, спавны, расстановка объектов, имя правил | — |
| Control | режимы мыши (курсор, толчок): ввод → намерение собаки, нажатые абилки | Bodies |
| Owners | типажи хозяев (`Types/`): поведение, тела (одно, несколько на привязи, закреплённое), масса, абилка; связь хозяин → собаки | Arena, Control, Bodies, Leashes |
| Dogs | породы (`Breeds/`): поведение, тела породы (у The Stack четыре на четырёх поводках), разгон, тяга приманок, оглушение, абилки | Arena, Control, Bodies, Hits, Leashes, Props |
| Props | объекты арены (`Kinds/`) на шести поведениях: препятствие, столб, подвижное тело, опасность по маршруту, приманка, зона трения/скорости | Arena, Bodies |
| Leashes | поводки: ломаная, обмотка о столбы (≤1 оборота), узлы двух поводков с таймером, натяжение | Arena, Bodies, Props |
| Bodies | 2D-физика: тела-круги, кинематические и закреплённые тела, ограничения поводков и привязей, зоны трения, столкновения, контакты тика | Arena |
| Hits | удары по собакам хозяином, машиной, объектом: сила, порог, отброс, оглушение | Bodies, Owners, Props |
| Rules | правила арены: активный набор правил по `rules` в json арены; наборы — классы в `Modules/Rules/<Имя>/`: `Sandbox` (песочница замаха, манекены, без очков), `Duel` (ХП собак на раунд, матч до 3 побед), `KingOfLawn` (круг, переезды, очки за круг и выбивание) | Arena, Bodies, Dogs, Hits, Match |
| Match | таймер, таблица очков, конец матча, победитель и отрыв | — |

Набор правил выбирается на матч по `rules` в json арены. Новая арена с новой целью добавляет класс набора в `Modules/Rules/<Имя>/`; если ему нужна новая связь, техлид дописывает её в строку `Rules`. Новая порода, типаж или вид объекта карту не меняют: это класс внутри своего модуля.
