# Карта модулей

Модуль владеет подсистемой целиком: своим состоянием, данными и правилами. `Simulation` шагает модули в порядке `GameSetup`. Модуль читает другой только через `sim.Need<T>(this, имя)` и только если назвал его в `DependsOn`. Контрактный тест сверяет `DependsOn` в коде с колонкой «Зависит от»: новая связь появляется правкой этой карты (её делает техлид при нарезке), а не попутно в фиче.

Порядок тика — сверху вниз. Модуль, стоящий выше, читает у стоящего ниже состояние прошлого тика.

| Модуль | Владеет | Зависит от |
|---|---|---|
| Arena | геометрия арены из `Data/arenas/`: границы, статичные препятствия, спавны, расстановка объектов, имя правил | — |
| Control | режимы мыши (курсор, толчок): ввод → намерение собаки, нажатые абилки | Bodies |
| Owners | типажи хозяев (`Types/`): поведение, масса, абилка; связь хозяин → собака | Control, Bodies, Leashes |
| Dogs | породы (`Breeds/`): поведение, тела породы (у The Stack четыре), разгон, оглушение, абилки | Control, Bodies, Hits, Leashes |
| Props | объекты арены (`Kinds/`): трафик, кошки, фонтаны, магазины; их тела, зоны и опоры | Arena, Bodies |
| Leashes | поводки: ломаная, точки намотки, узлы двух поводков, натяжение | Arena, Bodies, Props |
| Bodies | 2D-физика: тела-круги, кинематические тела, ограничения поводков, столкновения, контакты тика | Arena |
| Hits | удары по собакам хозяином, машиной, объектом: сила, порог, отброс, оглушение | Bodies, Owners, Props |
| KingOfLawn | правила «Царь газона»: круг, расписание переездов, очки за круг и выбивание | Arena, Bodies, Hits, Match |
| Match | таймер, таблица очков, конец матча, победитель и отрыв | — |

Модуль правил на месте `KingOfLawn` один на матч; `GameSetup` выбирает его по `rules` в json арены. Новая арена с новой целью добавляет строку своего модуля правил. Новая порода, типаж или вид объекта карту не меняют: это класс внутри своего модуля.
